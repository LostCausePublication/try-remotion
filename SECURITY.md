# Security policy

## Supported versions

The latest commit on `main` is the only supported version.

## Reporting a vulnerability

Please report vulnerabilities through GitHub private advisories:

https://github.com/LostCausePublication/try-remotion/security/advisories/new

Do not open a public issue for security reports.

You should receive an update within 7 days. If the report is accepted, we will work on a fix and credit you unless you ask otherwise.
