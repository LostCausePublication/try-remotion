# Contributing

Thanks for helping improve Try Remotion.

## Development

You need [Node.js](https://nodejs.org/) 22 or later.

```bash
npm i
npm run dev
```

Open the URL Vite prints. Use Chrome if you are testing MP4 export, and keep the tab visible while a render is in progress.

| Script | What it does |
| --- | --- |
| `npm run dev` | Start the web app |
| `npm run studio` | Open Remotion Studio with the sample logo |
| `npm run lint` | Run ESLint and TypeScript |
| `npm run build` | Production build |

## Pull requests

1. Open an issue first if the change is large or changes behavior.
2. Keep the diff focused on one problem.
3. Run `npm run lint` before you open the PR.
4. Fill in the pull request template.

## Code of conduct

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
